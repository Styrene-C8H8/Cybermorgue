关于本维度

"本区域独立于一切时间与空间，可理解为一个全新的维度。"——《员工手册》前言

当一位虚构作品中的角色在其原作里宣告死亡的那一刻，TA 并不会消散于虚无——TA 会在这里醒来。

赛博停尸间即是那扇门后的地方：一座漂浮在维度夹缝中的巨型设施，承担着所有"故事死者"的接收、登记、修复与安置工作。

分区规则只有一条：按原作的世界观类型划分。奇幻的归于奇幻，科幻的归于科幻——十二个收容分区，各自运转，互不打扰。

而维持这一切的，是一群被称为 STAFF 的存在。他们是这里的运营者、档案员、维修工与守夜人——也是本企划真正的主角。
